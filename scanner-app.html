設定 Google Sheets 自動記錄

1. 開啟 Google Sheets 建立一份新試算表

2. 點「擴充功能」→「Apps Script」，貼上程式碼後儲存：

function doPost(e) { var d = JSON.parse(e.postData.contents); var s = SpreadsheetApp .getActiveSpreadsheet() .getActiveSheet(); s.appendRow([ d.time, d.day, d.session, d.workshop, d.id, d.name, d.result ]); return ContentService .createTextOutput('ok'); }

3. 點「部署」→「新增部署」→ 類型：網頁應用程式 → 存取：所有人

4. 複製網址貼入上方欄位
